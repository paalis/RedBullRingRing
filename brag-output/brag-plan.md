# /brag-slim – plan: RBR '27 intro

**What it is:** A trip site for four friends going to the Austrian Grand Prix at the Red Bull Ring in July 2027.
**For whom:** The four of us (and everyone we send the link to). It gathers the program, route, track facts and packing list in one place.
**What sets it apart:** It's built as an F1 race weekend: the days are "sessions", the friends are drivers, the route is the strategy.
**Hook:** Five red start lights come on one by one on the beat, then lights out on the drop.
**Visual identity:** From `site/styles.css`: bg #0b0b10, red #e10600 / #ff2a1f, white, kerb stripes in red and white, Titillium Web 900 in uppercase and slanted.
**Tone:** cinematic: big type, dramatic kerb wipes, one strong drop.
**Duration:** 12 s (the user asked for "very short", which overrides the default 15–25 s). 1920×1080, 30 fps.
**Music:** 120 BPM (beat = 0.5 s, bar = 2 s), D minor. All cuts land on beats.
